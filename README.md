# Jungle King website preview

Public static website on GitHub Pages. Source: `Nicholassssssw/jungle-king-scan-lab`, Nicholas commit `edb09c7` (8 November 2026).

- Main scanner: https://nicholassssssw.github.io/jungle-king-preview/
- Scan demo and photo tests: https://nicholassssssw.github.io/jungle-king-preview/demo.html
- Result design examples: https://nicholassssssw.github.io/jungle-king-preview/result-preview.html

The bundled Hinson model automatically loads in the main scanner and demo. Seven trained animals: Grévy's Zebra, Philippine Eagle, Iberian Lynx, Tree Pangolin, Green Sea Turtle, Blue Whale and Leopard Cat, plus other. Fourteen bilingual stories exist; that does not mean all fourteen animals are trained.

A confident prediction repeated across four frames reveals its story and pauses scanning. The demo also supports multiclass model imports, optional one-piece browser training, held-out photo testing, adjustable demo thresholds and CSV reports. Photos and camera frames stay in the browser. Original animal illustrations for six new stories are labelled; they are not product replicas.

Source/model/data tests and browser integration checks passed. Physical-piece accuracy and real-phone performance remain unmeasured pending separate-session photos and device tests. Model scores are not measured accuracy. No training photos are published here.
