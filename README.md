# Jungle King website preview

Published static website files. The result page is a design prototype with sample animal stories. Live recognition remains unconfigured.

Source snapshot: Nicholas, commit a6fc66b. Root-relative model asset paths are normalized for GitHub Pages project hosting.

## Photo training demo

Open `demo.html` to train one piece from photos, check held-out examples, save/open a model ZIP, and try live camera recognition. Photos stay in the browser. Train on a computer first, save the ZIP, then reopen it on the device used for scanning. No trained product model is bundled.
